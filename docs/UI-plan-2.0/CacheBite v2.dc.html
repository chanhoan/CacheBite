Ring mode — single or double

v2 lets one overlay carry both providers. The pet is now cosmetic and user-chosen — it no longer encodes a provider — so the meaningful choice moves to the ring: single (one provider) or double (both). Same severity tokens and split-ring semantics as v1 (top arc = 5-hour, bottom arc = weekly, 5H / WK labels). Panel & settings are unchanged. Reference ids (7a, 7b) in chat.

§4 · overlay · ring mode

Pick the ring — the pet is just decoration

A single setting toggles the overlay between the two. Default is single. In double, the big ring is auto-bound to the primary provider and the satellite chip to the second — the user never assigns them by hand. Example load: primary 5h 82 (warn) / weekly 94 (critical) · second 5h 41 (ok) / weekly 58 (ok).

§4.1 · ui contract · overlay ring

UI contract — the two rings

This contract covers only the new double-ring overlay — ring positions, sizes, and the second-provider logo chip. The click panel (and its changes) and everything else follow the existing v1 contract unchanged.

C1 · mode
ring.mode : 'single' | 'double' — user setting. Default 'single'.
single → render one split ring for the primary provider only. The second provider is not shown on the overlay (still browsable in the panel).
double → render the primary split ring plus a satellite chip for the second provider.
C2 · provider binding (automatic)
Big ring ← providers.primary (the ★ set in settings). Satellite chip ← providers.secondary (the other connected one).
The user never maps a provider to a ring position by hand — binding is derived from the existing primary setting.
If connectedCount === 1: force effectiveMode = 'single' regardless of the setting; the lone provider takes the big ring.
If connectedCount === 0: overlay shows the pet with an unknown (grey) track, no arcs.
C3 · geometry & arcs (inherited from SplitUsageRing)
Big ring: two half-arcs on a 100×100 viewBox, stroke-width 6.5, round caps. Top arc M 8 50 A 42 42 0 0 1 92 50 = session (5-hour); bottom arc reversed = weekly. stroke-dasharray = `${percent} 100`, pathLength 100.
Labels: 5H at (50, 4), WK at (50, 104), mono / muted / letter-spacing 0.08em.
Satellite chip: same split-ring, ~40% scale, pinned lower-right, overlapping the big ring by ~⅓, on a white puck with drop-shadow. Center holds the second provider's logo (asset slot).
C4 · pet (cosmetic)
Pet is user-selected and carries no provider meaning. It always sits in the big ring center.
Mood/fatness still follows the big ring's provider: pet_mood = worst(session.sev, weekly.sev) of the primary. The satellite provider does not drive the pet.
C5 · per-ring states (independent)
stale → that ring dims to --overlay-stale-dim; the other ring is unaffected.
system != active (auth_required / unavailable / error / offline / loading) → that ring's arcs are replaced by the v1 system badge; the pet still renders. In double mode one provider erroring never blanks the other (provider-independence, §5).
unknown severity → grey track, no arc fill, no percentage.
